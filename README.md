# Растениум — определитель растений по фото (PWA-прототип)

Статический сайт без бэкенда (GitHub Pages, ветка gh-pages). Работает офлайн (service worker `plantarium-v1`).

**Что умеет:** фото → название (рус. + лат.) → параметры (свет, полив, температура, влажность, почва, токсичность для кошек и собак) → уточняющие вопросы при низкой уверенности → стадия/возраст (оценка по размеру и ответам) → план ухода с напоминаниями (localStorage, .ics, уведомление при открытии).

**Монетизация (заглушки):** 3 фото/день бесплатно → экран подписки (оплата не подключена); блок «Купить для ухода» со ссылками на поиск Ozon / Wildberries / Яндекс Маркет (шаблоны в `config.js`, место для партнёрских ID). Рекламы нет.

## Режим «Гровинг»
Культуры: клубника ремонтантная (горшок / гидропоника), микрозелень (горох, редис, подсолнечник, руккола, брокколи, кресс-салат, горчица, базилик), помидоры черри (подоконник / гроубокс).
Для каждой: свет (часы и спектр), полив, температура, влажность, субстрат, сроки до урожая, пошаговый календарь с задачами и напоминаниями (localStorage, .ics). Сроки ориентировочные.

## Регион и язык (Ещё → Регион и язык)
Россия / Казахстан / Другой (+ полушарие). Меняет сезоны (тёплый/отопительный), поправку сроков на тёмный сезон и окно старта в «Гровинге», магазины в ссылках (РФ: Ozon, WB, Я.Маркет; КЗ: Kaspi, Ozon, WB; другой: Amazon, AliExpress), валюту подписки (₽/₸/$) и язык интерфейса (ru; kk/en — частично). Список растений и культур от региона не зависит. Настройки в `config.js → REGIONS`.

## Распознавание
`config.js → PLANTNET_KEY`. Пусто = **демо-режим** (фото не анализируется, подбор по признакам из встроенной базы, 49 видов).
Ключ Pl@ntNet — публичный (для браузера): my.plantnet.org → Settings → API key → «Expose my API key» + «Authorized domains»: `https://dvsky001.github.io`.
Бесплатно: 500 распознаваний/день на аккаунт (общий лимит на всех пользователей).

## Иконки
PNG кладутся архивом `icons.tgz.b64`; GitHub Action `unpack-icons` распаковывает их в `icons/` и удаляет архив.

Данные ухода — общедоступные справочники, токсичность по спискам ASPCA. Не заменяет консультацию ветеринара или ботаника.
